# 🚀 Guía Rápida de Agentes

## Agentes Disponibles

| Agente | Comando | Especialidad |
|--------|---------|--------------|
| 🎨 **Design Web** | `/agent design-web` | UI/UX, Material Design, Accesibilidad |
| ⚛️ **Frontend** | `/agent frontend` | React, Astro, TypeScript, Componentes |
| 🏗️ **Arquitectura** | `/agent architecture` | Estructura, Patrones, Escalabilidad |

## Comandos Rápidos

```bash
# Ver todos los agentes disponibles
/agent

# Seleccionar un agente específico
/agent design-web

# Ejecutar múltiples agentes en paralelo
/fleet

# Ver instrucciones personalizadas
/instructions

# Ver variables de entorno y configuración
/env
```

## Casos de Uso

### 🎨 Usa Design Web para:
- Diseñar nuevas pantallas o componentes
- Mejorar la experiencia de usuario
- Asegurar accesibilidad
- Crear sistemas de diseño
- Revisar estilos y responsividad

### ⚛️ Usa Frontend para:
- Desarrollar componentes React
- Optimizar performance
- Escribir código TypeScript
- Realizar testing
- Integrar APIs

### 🏗️ Usa Arquitectura para:
- Planificar estructura del proyecto
- Tomar decisiones técnicas
- Definir patrones de diseño
- Documentación técnica
- Refactoring estratégico

## Ejemplo: Trabajar en un Componente

**Flujo recomendado:**

1. **Arquitectura** define la estructura y patrones
   ```
   /agent architecture
   > Diseña la estructura del componente
   ```

2. **Design Web** diseña la interfaz visual
   ```
   /agent design-web
   > Crea el mockup y guía de estilos
   ```

3. **Frontend** implementa el código
   ```
   /agent frontend
   > Desarrolla el componente en React/TypeScript
   ```

## Modo Fleet (Paralelo)

Para tareas complejas que requieren múltiples perspectivas:

```
/fleet
```

Luego especifica qué necesitas:
*"Necesito que diseñes, arquitectes e implementes un formulario de contacto profesional"*

Los tres agentes trabajarán en paralelo.
